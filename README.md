# pe-agentic-platform

The agentic layer for the Emergn Platform Engineer pathway, Module 3.

A runtime that contains agent runs, a policy layer that decides what an agent may do, an audit
trail the platform writes, and a golden path that provisions all three by default.

Built outside the client deliberately. No client code, credentials or infrastructure here.

See CLAUDE.md for the design decisions and docs/decisions.md for the log.
